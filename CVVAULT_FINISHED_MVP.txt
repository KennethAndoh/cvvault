1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
CVVault is a secure, professional SaaS platform designed for candidates and 
employers to store, organize, verify, and share career credentials and job 
opportunities. The MVP release includes full end-to-end authentication, document 
vault management, credential auto-verification, admin moderation workflow, 
public portfolio pages, time-bound access sharing with QR codes, job board & 
application processing, real-time messaging, AI tailored resume building, 
multi-channel notifications, and comprehensive audit logging.

--------------------------------------------------------------------------------
2. TECH STACK & INFRASTRUCTURE
--------------------------------------------------------------------------------
- Framework: Next.js 15 (App Router, Turbopack)
- Language: TypeScript
- Authentication: Firebase Authentication (Client SDK & Admin SDK)
- Database: Supabase PostgreSQL (via Service Role for secure server actions)
- File Storage: Supabase Storage ("documents" bucket)
- UI & Styling: Tailwind CSS v4, Shadcn UI / Radix Primitives, Lucide Icons, Framer Motion
- Form Management & Validation: React Hook Form, Zod schemas, @hookform/resolvers
- Notifications & Email: Novu Integration (@novu/nextjs, @novu/api), Resend Email API
- Development Tooling: ESLint, PostCSS, Bun / NPM
